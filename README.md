# 五目並べ（囲碁盤 Gomoku）

ブラウザ上で遊べる **PC（AI）対ユーザー** の五目並べゲームです。  
外部ライブラリやビルド環境は不要で、`index.html` をブラウザで開くだけですぐに対局できます。

---

## 遊び方

1. `index.html` をブラウザ（Chrome / Edge / Firefox / Safari など）で開きます。
2. サイドパネルで **難易度（Easy / Normal / Hard）** と **手番（先手・黒 / 後手・白）** を選択します。
3. 囲碁盤（15×15）の交点をクリックして石を置きます。
4. 縦・横・斜めのいずれかに自分の石を **5つ** 並べると勝利です。

---

## 主な機能・仕様

### 盤面・ビジュアル
- **15×15 の囲碁盤**（天元・四隅の星および A〜O / 1〜15 の座標表示付き）
- HTML5 Canvas による木目調（榧材風）の盤面と、那智黒石／蛤碁石風の立体的な石の描画
- 高DPI（Retina）ディスプレイ対応およびレスポンシブレイアウト
- カーソル位置の半透明プレビュー石表示
- 直前の着手マーカー表示
- 勝利時の 5 連ハイライト表示

### 対局コントロール・演出
- **難易度選択**: `Easy` / `Normal` / `Hard` / `AI`（Gemini・Claude API 連携）の 4 段階
- **AI API 設定（AIモード）**: プロバイダー（Gemini / Claude）、モデル名、APIキーを入力して実際の LLM と対局可能（着手理由の一言コメント付き）
- **手番選択**: 先手（黒）／後手（白）の切り替え（変更時は新しい対局を開始）
- **待った（Undo）**: 自分の直前の手番まで巻き戻し可能
- **新しい対局**: いつでも盤面をリセットして再戦可能
- **セッション戦績**: 現在のセッション中の勝ち・負け・引き分け数をカウント
- **効果音（Web Audio API）**: 外部音声ファイル不要の合成打石音・決着チャイム（右上のボタンで ON / OFF 切り替え可能）

### ルール
- 黒（先手）と白（後手）が交互に盤面の交点へ 1 つずつ石を置きます。
- 縦・横・斜めのいずれかの直線上に自分の石を **5つ以上** 並べた側の勝利です。
- 禁じ手（三三・四四・長連の反則）のない標準的な五目並べルールを採用しています。
- 盤面の全 225 交点が埋まっても勝敗がつかない場合は引き分けとなります。

## 難易度（AIモード）ごとの違い

`ai.js` に実装している 3 つのモードは、**先読みの深さ・脅威への反応精度・ランダム性** によって強さを段階分けしています。

### 比較表

| 項目 | Easy | Normal | Hard |
| :--- | :--- | :--- | :--- |
| **思考方式** | 局所評価＋強めのランダム選択 | 1手読み（攻防スコア合算） | アルファベータ探索（深さ4） |
| **即勝ち（5連）** | 約75%の確率で打つ（見逃すことあり） | 必ず打つ | 必ず打つ |
| **相手の4連阻止** | 約60%の確率で止める（見逃すことあり） | 必ず止める | 必ず止める |
| **先読み** | なし（現局面の評価のみ） | 1手先まで | 最大4手先まで（相手との応酬を読む） |
| **ランダム性** | 高い（上位8手ほどから確率選択） | 低め（僅差の上位手から選択） | なし（探索結果の最善手を選択） |

### 各モードの詳細

#### Easy（初心者向け）
- 既存の石の周囲（半径2マス以内）から候補を抽出し、上位 8 手前後の中からランダム寄りに着手を選びます。
- 自分の 5 連チャンスや相手の 4 連（リーチ）を一定確率で見逃すため、五目並べに慣れていない方でも気軽に勝利できます。

#### Normal（標準）
- 各空きマスについて「自分が置いたときの攻撃スコア」と「相手が置いたときの防御スコア（×1.05）」を合算して評価します。
- 5 連での即勝ち、相手の 4 連阻止、活四（両端が空いた 4 連）の作成・阻止を確実に行い、活三・飛び三・四三などの複合形も局所評価で認識します。
- 2 手以上先の応酬までは読まないため、複数手にわたる罠や先手を組み合わせた追い詰めには隙が生まれることがあります。

#### Hard（上級者向け）
- **アルファベータ法（探索深さ 4）** により、「自分の手 → 相手の応手 → 自分の次の手 → 相手の応手」までシミュレーションして最善手を選びます。
- 候補手を事前評価で絞り込む **ムーブオーダリング** と、最大約 1.1 秒の **時間制限ガード** を組み合わせることで、快適な応答速度を保ちながら高精度な探索を行います。
- 末端の盤面評価では、石の連なりだけでなく「次手番に四があるか（実質勝利）」「防御不能な活四・両四があるか」「活三で先手を取れるか」といった戦術的な優劣まで判定します。

#### AI（LLM API 連携モード）
- **Gemini API**（デフォルト: `gemini-2.5-flash`）または **Claude API**（デフォルト: `claude-sonnet-4-5`）に現在の盤面と棋譜を送信し、実際の生成AIと対局するモードです。
- サイドパネルで **AI** を選択すると API 設定欄が表示され、APIキーを入力するだけで対局できます。
- **モデルの検索・選択機能**:
  - 入力欄をクリックすると主要モデルのプリセット一覧（推奨・高速・高精度などのタグ付き）が表示され、キーワードで絞り込み検索・選択できます。
  - **「🔄 APIから取得」** ボタンを押すと、入力した API キーを使って Gemini / Claude の公式 API から実際に利用可能な最新モデル一覧を取得して選択できます。
- AI が選んだ手とともに **短い日本語の着手コメント** がステータス欄に表示されます。
- 万が一、LLM が既に石のあるマスを返した場合は自動で 1 回リトライし、通信エラー等が発生した場合はエラー内容を表示したうえでローカルの `Hard` アルゴリズムが代打ちして対局を継続します。
- **プライバシー・セキュリティ**: APIキーはブラウザから Google / Anthropic の公式 API へ直接送信され、第三者サーバーには送信されません。「このブラウザにキーを記憶する」をオンにした場合のみ `localStorage` に保存されます。

```text

├── game.js      # Canvas描画・入力制御・Web Audio効果音・UI状態管理

```

## 技術仕様

- **フロントエンド**: HTML5 / CSS3 / Vanilla JavaScript（フレームワーク・外部パッケージ不使用）
- **描画**: HTML5 Canvas 2D API（オフスクリーン Canvas による木目テクスチャキャッシュ）
- **音声**: Web Audio API（バンドパスフィルタ付きノイズ＋減衰トーンによる打石音合成）
- **AI モジュール**: `ai.js` はブラウザ（`window.GomokuAI`）と Node.js（`module.exports`）の両方に対応しており、CLI 上から自動対戦やロジックテストを実行可能です。
